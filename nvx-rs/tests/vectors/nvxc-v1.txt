# Conformance vectors of version 1 of the NVX control protocol: its NVXC application frames,
# their EXEC, MAPS, and features payloads, and NVXS records of the session that carries them.
# README.md describes the line format and the rules that the vectors follow.
#
# RECORD|NAME|BYTES|TYPE|INSTANCE|EPOCH|SEQUENCE|PAYLOAD
#   An NVXS record. TYPE is GUEST_ATTACH, HOST_ATTACH, RESET, ACK, DATA, WAIT, READY, ERROR, or
#   CREDIT, and INSTANCE, the instance ID, and PAYLOAD are byte strings.
# FRAME|NAME|BYTES|KIND|REQUEST|STATUS|PAYLOAD
#   An NVXC frame. KIND is PING, EXEC, STOP, CANCEL, FEATURES, MAPS, READY, STDOUT, STDERR, EXIT,
#   STOPPED, or ERROR, REQUEST is the request ID, STATUS the signed status, and PAYLOAD a byte
#   string.
# EXEC|NAME|BYTES|TIMEOUT|ARGUMENTS|DIRECTORY|ENVIRONMENT
#   The payload of an EXEC request. TIMEOUT is in milliseconds, ARGUMENTS is a list of texts, the
#   program first, and DIRECTORY is a text or absent. ENVIRONMENT is DEFAULT, for the guest's
#   default environment, or LAYERED or REPLACED followed by a list of KEY=VALUE texts, which
#   layer over the default environment or replace it.
# MAPS|NAME|BYTES|FIRST|ENTRIES
#   The payload of a MAPS request: the index of its first entry in the host mapping table, and a
#   list of entries, each ACCESS|SOURCE|TARGET, with ACCESS RO or RW and the paths as texts.
# FEATURES|NAME|BYTES|BITS
#   The payload of the response to a FEATURES request: the bit mask of the guest's features.
# INVALID_MAPS|NAME|BYTES
#   A MAPS payload that every decoder refuses.
