# 1.1 Goals

[Architecture documentation](README.md) >
[1. Architecture Overview](1-architecture-overview.md)

The architecture has the following goals:

- Boot the same uncompressed Linux-direct kernel on Linux and Windows hosts.
- Keep the guest-visible machine independent of the selected hypervisor.
- Expose only a fixed, allowlisted set of devices.
- Capture a running VM into immutable artifacts that can be restored in a new
  process without serializing native host handles.
- Run exactly one workload per microVM.
- Assemble the workload filesystem from an immutable image layer, a private
  writable upper on scratch or in guest memory, and optional live host shares.
- Keep workload policy and host-resource attachment under host control.
