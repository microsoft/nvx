# CI's runtime adapter step runs by name on each backend, with
# `python3 scripts/nvx.py test-runtime-adapter`. Each line names a test target of `tests/`, then
# one of its tests, which the step runs whether it is ignored or not. The step fails once a line
# names a test that its target does not have, a target that a line names has a test that no line
# names, the library or a target that no line names has an ignored test, or a named test does not
# run and pass. The README's "Stage scenarios" says what each scenario proves.
